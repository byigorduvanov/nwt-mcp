Карточки графа NWT

Как чужой AI-агент находит наши данные о пластиках и рыночных символах быстро и дёшево: он не получает весь каталог сразу, а спускается от карты к нужной карточке.

Проблема

Агент начинает с нуля

Клиент подключает своего агента (Claude, ChatGPT, Cursor) к нам через MCP. В каждом новом разговоре агент ничего не знает о наших данных.

Память агента мала и платна

Всё, что мы ему даём, занимает контекст. Каждый токен стоит денег и времени, а лишнее мешает агенту думать.

Данные нужно понять, а не только найти

EUR/кг или USD/т, CFR или FOB, HDPE — это разновидность PE, а производят его из этилена. Без этого агент уверенно ошибается.

Карта типов и карточки

14 типов узлов в двух деревьях. Нажмите на тип: под схемой появится его карточка (что это, какие поля, связи) и пример карточки узла. Это то, что агент получает через nwt_get.

Один вопрос, шаг за шагом

«Сколько стоит HDPE плёнка в Европе и что влияет на цену?» Ниже — настоящие ответы сервера на каждый вызов и их размер.

Четыре правила, которые экономят токены

Проверено на 300 сессиях

100 вопросов от разных клиентов (закупщик, трейдер, аналитик, технолог, дата-инженер, переработчик) на пяти языках. Каждый — отдельная сессия Claude, которая видит только наш MCP. Три прогона: до исправлений и после двух раундов исправлений.

Тест нашёл 11 недочётов сервера, например: полимер «без цен», хотя цены есть у его разновидностей; название вместо кода давало ошибку; список символов обрезал самые важные позиции. Все исправлены. Полный отчёт с каждым вопросом и ответом: отчёт о тесте.

Как попробовать и что ещё не готово

Попробовать

  1. Открыть новую сессию Claude Code в папке ~/work/nwt: сервер nwt-data подключён на уровне проекта.
  2. Спросить обычным языком, например «из чего делают ПЭТ» или «какие ценовые ряды есть для HDPE в Европе».
  3. Код сервера, тесты и тестовый стенд: ~/work/nwt/nwt-mcp (GitHub: byigorduvanov/nwt-mcp), запуск тестов uv run pytest -q.
  4. Просмотрщик графа с вкладкой «Агент» (карточки, которые получает агент, для любого узла): uv run nwt-mcp view.
